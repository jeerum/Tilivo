# UI design (v0.4)

- Desktop-first AppShell: vasak sidebar + lai topbar + sisupaneel.
- Breakpointid: >=1280 lai töölaud, 900–1279 tablet/small, <900 mobiilne.
- Mobiilis sidebar peidetud (drawer tulevikus), sisu ühes tulbas.
- Auth-lehed jäävad keskmise kaardiga; autenditud rakendus on lai.
- Värvid: valge/helendav hall, punane ainult warning/error.
